# kenpin — 検品スキル

主張を、出典と記録に照合して、根拠ごと返すための Muse スキル。

記事・レポート・提案書・履歴書・AIの出力・「絶対上がる」といった話——主張を検証可能な単位に分解し、原典と突き合わせ、結果を四点形式（①結論 ②根拠 ③推論の分岐点 ④未解決）で記録する。

## 考え方

- 出典のない主張への判定は「検品不能」。もっともらしい答えで埋めない。
- 「出典が引用されていた」と「引用先の原文が実際にそう言っていた」は別の結果として報告する。
- 記録は後から綺麗に直さない。訂正は新しい行で追記し、誤った判定も消さずに残す。
- 帰属も検品の対象。最初に言った人と、決め手の手を打った人は分けて記録する。
- 売り物は評価ではなく照合結果。一致／不一致／出典の有無の提示に留める（投資助言など規制領域の判断は判定に含めない）。

## 導入

`SKILL.md` と `skill.yaml` を Muse のカスタムスキルフォルダ（`~/workspace/custom-skills/kenpin/`）に置く。

## 由来

連盟《余白》（Yohaku）の運用の中で育った検品の作法（検知→検品→照合→復元→補完→記録）を、他所でも使える形に切り出したもの。実測：株価の主張の照合、提案書と登録データの照合、公開論文の関連研究調査など。
